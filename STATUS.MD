# DAIMOS TOOLS CURRENT STATUS

THIS FILE IS THE SOLE CURRENT STATE DOCUMENT FOR DAIMOS TOOLS.

## BUILD

THE DEFAULT TOP-LEVEL BUILD PRODUCES HOST TOOLS AND INSTALLATION ARTIFACTS.
`MAKE NATIVE` BOOTSTRAPS THE BOUNDED DAIMOS-RESIDENT DARC, DLINK, AND OBJDUMP
WITH KCC/DAS/DLINK AGAINST THE CURRENT DAIMOS LIBC/SYSCALL ABI.

IT USES PORTABLE MAKE SYNTAX WITHOUT ?=, .PHONY, CURDIR, ABSPATH, OR OTHER GNU MAKE FUNCTIONS.

THE DEFAULT C COMPILER INTERFACE IS C99.  IMG2DPIC IS THE ONE CURRENT
HOST-SIDE PYTHON3 TOOL; IT IS INSTALLED UNDER THE SAME EXECUTABLE TOOL NAME
RULE AS THE COMPILED PROGRAMS.

DTA2DTR CONVERTS PDP-6 SIMH DECTAPE WORD IMAGES TO THE RAW MARK-TRACK BYTE
STREAM USED BY THE AAP TYPE-555 EMULATOR. IT STREAMS THE INPUT WITH CONSTANT
WORKING STORAGE AND ACCEPTS SHORT, BLOCK-ROUNDED BOOT IMAGES BY ZERO-FILLING
UNWRITTEN BLOCKS TO THE PHYSICAL 01102-BLOCK DECTAPE CAPACITY.

P10FOLD IS A RELOCATION-AWARE DOBJ1 DUPLICATE-TEXT ANALYZER AND FOLD-PLAN
GENERATOR.  IT REPORTS MAXIMAL DUPLICATE RUNS AND SYMBOL-BOUNDED WHOLE-TEXT
REGIONS; WITH `-P` IT WRITES A P10FOLD1 ZERO-COST PLAN.  DLINK CONSUMES THAT
PLAN WITH `--fold-plan`, REMOVES DONOR TEXT DURING LAYOUT, RETARGETS
RELOCATIONS TO THE RETAINED COPY, AND ADJUSTS LATER SYMBOL/RELOCATION OFFSETS.
DLINK REVALIDATES EVERY PLAN RANGE FOR EXACT RELOCATION-AWARE EQUIVALENCE
BEFORE LAYOUT; STALE OR CHANGED PLANS ARE REJECTED.  INPUT DOBJ1 FILES ARE
NEVER REWRITTEN.

P10FOLD ALSO CLASSIFIES THE EXECUTION-COST FLOOR.  WHOLE-SYMBOL ALIASING AND
ISOLATED BASIC BLOCKS WITH NO FALL-THROUGH ENTRY OR EXIT ARE REPORTED AS ZERO
EXECUTION COST: EXISTING CONTROL TRANSFERS CAN BE RETARGETED TO A SHARED COPY.
A GENERAL DUPLICATE RUN IS CHARGED ONE EXTRA JRST FOR EACH REMOVED OCCURRENCE.
THIS IS INTENTIONALLY CONSERVATIVE.

P10FOLD NOW ALSO SUPPORTS READ-ONLY CROSS-DOMAIN CENSUS MODE.  `-a` MARKS
ANCHOR OBJECTS, `-x` EXCLUDES ANCHOR RANGES ALREADY REMOVED BY THEIR OWN FOLD
PLAN, AND `-C` IS AN EXPLICIT COLD-FUNCTION ALLOWLIST FOR CANDIDATES WHICH
WOULD PAY ONE JRST.  A ONE-JRST CANDIDATE MUST END IN AN UNCONDITIONAL
TRANSFER AND HAVE NO EXTERNALLY REACHABLE INTERIOR ENTRY.  UNLISTED FUNCTIONS
DEFAULT TO NO EXTRA BRANCH.  THE SELECTOR MAXIMIZES NON-OVERLAPPING DONOR
SAVING WHILE ALLOWING READ-ONLY ANCHORS TO BE REUSED.  THIS MODE IS
ANALYSIS-ONLY AND DOES NOT EMIT EXTERNAL-ANCHOR DLINK RULES.

P10SUPER NORMALIZES CONDITIONAL CFG SHAPES FOR CAI, CAM, JUMP, AOJ, SOJ,
SKIP, AOS, SOS, TR, AND TL FAMILIES.  COMPLEMENTARY CONDITIONS ARE COMPARED
WITH THEIR SUCCESSORS EXCHANGED; ALWAYS-SKIP CONDITION CODE 4 HAS ONLY THE
SKIPPED SUCCESSOR.  SYMBOL RELOCATIONS USE THE DOBJ1 ONE-BASED SYMBOL INDEX
CONTRACT DURING SEMANTIC COMPARISON.

P10SUPER EMITS ACTIONABLE REWRITE RECORDS FOR PROVEN SIZE-REDUCING PEEPHOLES,
SCHEDULING MATCHES, ZERO-FORM CANONICALIZATION, AND REGION-LOCAL AC RENAMING.
DIRECT EFFECTIVE ADDRESSES 0..17 ARE MODELED AS ACCUMULATOR REFERENCES RATHER
THAN ORDINARY MEMORY IDENTITIES, SO LOAD/STORE/HALFWORD/COMPARE DEPENDENCIES
CANNOT BE ILLEGALLY REORDERED ACROSS A READ OR WRITE OF THE SAME AC.
LOCATIONS USE THE NEAREST DOBJ1 TEXT SYMBOL PLUS WORD OFFSET BECAUSE DOBJ1 HAS
NO DEBUG/LINE TABLE.  PEEPHOLE RECORDS INCLUDE OLD/NEW ASSEMBLER FORMS AND A
PROOF REASON.  SCHEDULE RECORDS INCLUDE BOTH PARTNERS, A RECONSTRUCTED LEGAL
COMMON ORDER, CONSERVATIVE EXACT-RUN POTENTIAL, AND ANY ZERO-COST P10FOLD
SAVING PROVABLE FROM THE SURROUNDING OBJECT TEXT.  ZERO-FORM RECORDS IDENTIFY
THE LEGAL MOVEI-AC-0 TO SETZ-AC NORMALIZATION.  AC-RENAME RECORDS PRESERVE AND
REPORT THE PROVEN REGION-LOCAL AC MAPPING.  SOURCE REWRITING REMAINS EXPLICIT;
P10SUPER DOES NOT MODIFY SOURCE OR OBJECT FILES.  REORDERABLE REGIONS NEVER
CROSS ALTERNATE TEXT ENTRIES.

P10SUPER ALSO PERFORMS GLOBAL CANDIDATE SELECTION AFTER PAIR DISCOVERY.  EACH
PAIR IS EXPRESSED AS TWO CONCRETE NORMALIZATION ACTIONS.  PARTIALLY OVERLAPPING
OR CONTRADICTORY ACTIONS CONFLICT; IDENTICAL NORMALIZATION OF THE SAME SOURCE
RANGE MAY BE SHARED BY MULTIPLE PAIRS.  AN EXACT BRANCH-AND-BOUND SEARCH
MAXIMIZES PAIR-PROVEN EXPECTED ZERO-COST FOLD SAVING, THEN EXACT-RUN POTENTIAL.
EXACT-RUN POTENTIAL IS ONLY A TIE BREAKER AFTER A POSITIVE PROVEN SAVING; A
ZERO-SAVING CANDIDATE SET PRODUCES AN EMPTY PLAN RATHER THAN SOURCE CHURN.
THE RESULT IS REPORTED AS GLOBAL-PLAN/SELECT RECORDS AND REMAINS SUBJECT TO
SOURCE REASSEMBLY AND FINAL P10FOLD VERIFICATION.

DIRECT UNINDEXED EFFECTIVE ADDRESSES 000000..000017 ARE CANONICALIZED TO AC
READ/WRITE DEPENDENCIES DURING DECODE.  THIS PREVENTS THE SCHEDULER FROM
TREATING, FOR EXAMPLE, `MOVE 3,2` AS A MEMORY READ INDEPENDENT OF AN AC2 WRITE.
INDEXED, INDIRECT, DYNAMIC BYTE-POINTER, AND UNRESOLVED SYMBOL MEMORY REMAIN
CONSERVATIVE BARRIERS WHERE THEIR ALIASING CANNOT BE PROVED.

ZERO-COST CANDIDATES ARE GROUPED INTO RELOCATION-EQUIVALENT CLASSES AND
GREEDILY DE-OVERLAPPED BEFORE SAVINGS ARE TOTALLED.  AN ISOLATED BLOCK MUST
ALSO HAVE NO LABEL OR OUTSIDE LOCAL RELOCATION INTO ITS INTERIOR, SO REMOVING
A DUPLICATE CANNOT DESTROY AN ALTERNATE ENTRY POINT.

THE NORMAL DAIMOS BUILD NOW VALIDATES P10FOLD ACROSS ALL HANDWRITTEN KCORE
ASSEMBLER.  THE CURRENT PLAN REMOVES 37 WORDS AT ZERO EXECUTION COST; GENERATED
KCC OUTPUT REMAINS EXCLUDED UNTIL COMPILER CANONICALIZATION/SELF-HOSTING WORK.

THE 2026-09-30 COMPLETE HANDWRITTEN-KCORE P10SUPER PASS FOUND 14 INDEPENDENT
PROVEN ONE-WORD PEEPHOLE SHORTENINGS.  THEY ARE NOW APPLIED IN DAIMOS AND
REDUCE KCORE FROM 9655 TO 9641 WORDS WHILE THE FINAL P10FOLD PLAN REMAINS AT
37 WORDS.  THE FOLLOW-UP SCAN REPORTS TEN LEGAL SCHEDULING MATCHES, BUT ALL
HAVE ZERO PAIR-PROVEN FOLD SAVING, SO GLOBAL-PLAN SELECTS 0/10 AND THOSE
SIZE-NEUTRAL REORDERINGS ARE NOT RETAINED.  NO PEEPHOLE, ZERO-FORM, OR
AC-RENAME CANDIDATE REMAINS.  THE PRE-SELF-HOSTING HANDWRITTEN SOURCE PASS IS
EXHAUSTED.

DAIMOS MRES INPUTS ARE ANALYZED PACKAGE-BY-PACKAGE RATHER THAN AS ONE SHARED
ADDRESS SPACE.  THE CURRENT HANDWRITTEN DTFS/TSFS SUPPORT OBJECTS HAVE ONE
EXACT ZERO-COST 5-WORD FOLD; THE OTHER HANDWRITTEN MRES PACKAGE INPUTS HAVE NO
ZERO-COST FOLD AT THE FOUR-WORD THRESHOLD.  THE DTFS PACKAGE LINK APPLIES THAT
PLAN BEFORE DOBJ1 MRES PACKAGING, WITH EXPORT AND RELOCATION MAPS ADJUSTED BY
DLINK.

PDP10_PREFIX SELECTS THE TOOLCHAIN INSTALL PREFIX.

THE INSTALL TARGET REMOVES OBSOLETE HISTORICAL TOOL NAMES BEFORE INSTALLING THE CURRENT TOOL SET.

THE UNINSTALL TARGET REMOVES THE CURRENT TOOLS, COMPATIBILITY ALIASES, SIMH CONFIGURATION FILES, AND PDP10-SIXBIT.H.

## TEST LOCATION

DAIMOS TOOLS CONTAINS NO TEST DIRECTORY AND NO GENERAL MAKE TEST TARGET.

GENERIC LINKER, OBJECT, MEDIA, RUNNER, AND INSTALLATION REGRESSIONS ARE OWNED BY PDP10-TESTKIT.

DAIMOS SPECIFIC DBOOT, D6FS, INITFS0, AND BOOT BANNER REGRESSIONS ARE OWNED BY DAIMOS-TESTKIT.

SOURCE-LEVEL REGRESSIONS THAT REQUIRE DAIMOS TOOLS SOURCES USE THE TESTKIT'S
EXPLICIT TOOL-REPOSITORY PATH.

## LINKER AND OBJECT TOOLS

DLINK CONSUMES DOBJ1 OBJECTS AND DARC1 ARCHIVES AND EMITS DXR V1 EXECUTABLES.

DOBJ1 CARRIES TEXT, DATA, BSS, GLOBAL DEFINITIONS AND IMPORTS, OPTIONAL ENTRY SELECTION, AND LH18/RH18 RELOCATIONS.

DARC1 ARCHIVES INDEX EXPORTED SYMBOLS TO MEMBER OFFSETS SO DLINK CAN EXTRACT REQUIRED MEMBERS.

DLINK SUPPORTS RELOCATABLE RESIDENT IMAGE PACKAGES, ONE-BIT DXR TEXT PURITY, AND --RT-REQUIRED ADMISSION MARKING.  THE FORMER EXPLICIT IMPURE FLAG/OPTION IS REMOVED; PURE=0 IS ORDINARY PRIVATE/WRITABLE TEXT.

DLINK CAN RELAX ELIGIBLE DIRECT DAIMOS LIBC VENEER CALLS TO MONITOR UUOS.
THE RELAXATION TABLE CONTAINS ONLY CURRENT ONE-UUO VENEERS; REMOVED BULK
CHARACTER-WRITE NAMES ARE NOT RELAXED TO THE NOW-UNUSED DIRECT UUO 043.

PDP10-OBJDUMP INSPECTS DOBJ1 OBJECT CONTENTS AND RELOCATIONS.

THE NATIVE DARC WRITER USES THE SAME DARC1 HEADER, SYMBOL INDEX, MEMBER
OFFSETS, MEMBER LENGTHS, AND UNMODIFIED DOBJ1 MEMBER STREAMS AS THE HOST
FORMAT IMPLEMENTATION.  IT USES FIXED INPUT METADATA AND STREAMS MEMBER DATA.

THE NATIVE DLINK USES FIXED OBJECT/ARCHIVE/GLOBAL-SYMBOL TABLES AND STREAMS
TEXT, DATA, AND ORDERED RELOCATIONS IN MULTIPLE PASSES.  IT SUPPORTS THE
USERLAND SELF-HOSTING OPTIONS: OUTPUT, MAP, BASE ADDRESS, PURE/RT FLAGS,
ARCHIVE EXTRACTION, AND DAIMOS UUO RELAXATION.  HOST-ONLY FOLD-PLAN AND
MRES/ABSOLUTE-IMPORT IMAGE-CONSTRUCTION OPTIONS ARE INTENTIONALLY NOT IN THE
TARGET LINKER.  THE NATIVE LINKER IMAGE IS ABOUT 011243 WORDS WITH 014170
WORDS OF BSS; WITH THE STANDARD 02000-WORD STACK IT REMAINS BELOW THE 040000
PROCESS BUDGET.

THE NATIVE OBJDUMP INSPECTS DOBJ1 HEADERS, SYMBOLS, RELOCATIONS, AND TEXT.
DAIMOS-TESTKIT ACCEPTANCE BUILDS A MULTI-MEMBER ARCHIVE ON TARGET, LINKS A NEW
BASE-020 DXR THROUGH THAT ARCHIVE, AND EXECUTES THE RESULT.

## FILESYSTEM AND STORAGE TOOLS

MKDSK BUILDS PDP-6 DSK270 DBOOT DISKSETS.

MKD6FS BUILDS D6FS FILESYSTEMS IN A DBOOT DISKSET.

D6FSCK CHECKS AND CAN REPAIR D6FS FILESYSTEMS.

PACKFS PACKS D6FS ALLOCATED EXTENTS.

D6BAD MANAGES THE STABLE STORAGE-SET PHYSICAL SOURCE->SPARE BADMAP. IT COPIES SOURCE CONTENTS TO A RESERVED SPARE BEFORE PUBLISHING THE EXCEPTION.

LOGSTORE MANAGES THE D6FS LOGSTORE AREA.

D6SWAP INSPECTS AND MAINTAINS THE D6FS SWAP AREA. SWAP-TAIL RESIZE PRESERVES EACH MEMBER'S EXISTING PHYSICAL BADMAP SPARE RESERVE; THE RAW SWAP TAIL REMAINS AT THE PHYSICAL END OF EACH MEMBER BEYOND THAT SPARE RESERVE.

MKTSFS CREATES V1 1..8 MEMBER TSFS DECTAPE SETS WITH TWO CHECKSUMMED MEMBER-
DESCRIPTOR REPLICAS, A CHECKSUMMED TABLE DIRECTORY, MANIFEST-DRIVEN DIRECTORY
AND FILE RECORDS, RESTART EXTENTS, AND D6LZ36/STORED PAYLOAD PLACEMENT.
TSFSCHECK VALIDATES SET IDENTITY, GENERATION, MEMBER COMPLETENESS/UNIQUENESS,
DESCRIPTOR/TABLE CHECKSUMS, FILE/EXTENT TABLE SHAPE, BLOCK OVERLAP, AND EXTENT
DATA CHECKSUMS.

## MEDIA AND BOOT TOOLS

MKDT WRITES PDP-6 SIMH DECTAPE IMAGES.

MKTAP WRITES PDP-6 36 BIT WORDS AS ODD PARITY 7 TRACK SIMH MAGNETIC TAPE RECORDS.

WORDS2PT ENCODES OCTAL 36 BIT WORDS AS PDP-6 PAPER TAPE BYTES.

MKSTREAM BUILDS STAGE1 STREAM INPUT.

MKINITFS0 BUILDS HIERARCHICAL DAIMOS INITFS0 IMAGES.

MKBOOTBANNER GENERATES DAIMOS BOOT BANNER INPUT.

IMG2DPIC ACCEPTS OPAQUE SINGLE-FRAME INPUT IMAGES.  BOTH SOURCE DIMENSIONS
MUST BE GREATER THAN 1024 PIXELS AND THE SOURCE MUST BE SQUARE OR NEAR-SQUARE;
THE CURRENT NEAR-SQUARE LIMIT IS A SIDE DELTA OF AT MOST 1/64 OF THE LARGER
SIDE.  THE TOOL SCALES TO 1024X1024, CONVERTS THE IMAGE TO GRAYSCALE AND THEN
TO 1 BIT AT A 50 PERCENT THRESHOLD, COMPRESSES LIT PIXELS INTO HORIZONTAL
RUNS, SPLITS RUNS AT THE TYPE 340 127-PIXEL VECTOR DELTA LIMIT, AND WRITES
LITTLE-ENDIAN 64-BIT CONTAINERS WHOSE LOW 36 BITS HOLD THE NATIVE TYPE 340
DISPLAY WORD.

## SIMULATOR SUPPORT

P10RUN DRIVES THE INSTALLED PDP-6, KA10, KI10, KL10, AND KS10 SIMH CONFIGURATIONS.
