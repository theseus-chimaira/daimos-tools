# PDP10 TOOLS CURRENT STATUS

THIS FILE IS THE SOLE CURRENT STATE DOCUMENT FOR PDP10 TOOLS.

## BUILD

THE TOP LEVEL MAKEFILE BUILDS ONLY HOST TOOLS AND INSTALLATION ARTIFACTS.

IT USES PORTABLE MAKE SYNTAX WITHOUT ?=, .PHONY, CURDIR, ABSPATH, OR OTHER GNU MAKE FUNCTIONS.

THE DEFAULT C COMPILER INTERFACE IS C99.

PDP10_PREFIX SELECTS THE TOOLCHAIN INSTALL PREFIX.

THE INSTALL TARGET REMOVES OBSOLETE HISTORICAL TOOL NAMES BEFORE INSTALLING THE CURRENT TOOL SET.

THE UNINSTALL TARGET REMOVES THE CURRENT TOOLS, COMPATIBILITY ALIASES, SIMH CONFIGURATION FILES, AND PDP10-SIXBIT.H.

## TEST LOCATION

PDP10 TOOLS CONTAINS NO TEST DIRECTORY AND NO MAKE TEST TARGET.

GENERIC LINKER, OBJECT, MEDIA, RUNNER, AND INSTALLATION REGRESSIONS ARE OWNED BY PDP10-TESTKIT.

DAIMOS SPECIFIC DBOOT, D6FS, INITFS0, AND BOOT BANNER REGRESSIONS ARE OWNED BY DAIMOS-TESTKIT.

SOURCE LEVEL REGRESSIONS THAT REQUIRE PDP10 TOOLS SOURCES USE PDP10_TOOLS_REPO EXPLICITLY FROM THE TESTKIT.

## LINKER AND OBJECT TOOLS

DLINK CONSUMES DOBJ1 OBJECTS AND DARC1 ARCHIVES AND EMITS DXR V1 EXECUTABLES.

DOBJ1 CARRIES TEXT, DATA, BSS, GLOBAL DEFINITIONS AND IMPORTS, OPTIONAL ENTRY SELECTION, AND LH18/RH18 RELOCATIONS.

DARC1 ARCHIVES INDEX EXPORTED SYMBOLS TO MEMBER OFFSETS SO DLINK CAN EXTRACT REQUIRED MEMBERS.

DLINK SUPPORTS RELOCATABLE RESIDENT IMAGE PACKAGES AND DXR TEXT PURITY STATE.

DLINK CAN RELAX ELIGIBLE DIRECT DAIMOS LIBC VENEER CALLS TO MONITOR UUOS.

PDP10-OBJDUMP INSPECTS DOBJ1 OBJECT CONTENTS AND RELOCATIONS.

## FILESYSTEM AND STORAGE TOOLS

MKDSK BUILDS PDP-6 DSK270 DBOOT DISKSETS.

MKD6FS BUILDS D6FS FILESYSTEMS IN A DBOOT DISKSET.

D6FSCK CHECKS AND CAN REPAIR D6FS FILESYSTEMS.

PACKFS PACKS D6FS ALLOCATED EXTENTS.

D6BAD MANAGES D6FS BAD BLOCK INFORMATION.

LOGSTORE MANAGES THE D6FS LOGSTORE AREA.

D6SWAP INSPECTS AND MAINTAINS THE D6FS SWAP AREA.

## MEDIA AND BOOT TOOLS

MKDT WRITES PDP-6 SIMH DECTAPE IMAGES.

MKTAP WRITES PDP-6 36 BIT WORDS AS ODD PARITY 7 TRACK SIMH MAGNETIC TAPE RECORDS.

WORDS2PT ENCODES OCTAL 36 BIT WORDS AS PDP-6 PAPER TAPE BYTES.

MKSTREAM BUILDS STAGE1 STREAM INPUT.

MKINITFS0 BUILDS HIERARCHICAL DAIMOS INITFS0 IMAGES.

MKBOOTBANNER GENERATES DAIMOS BOOT BANNER INPUT.

## SIMULATOR SUPPORT

P10RUN DRIVES THE INSTALLED PDP-6, KA10, KI10, KL10, AND KS10 SIMH CONFIGURATIONS.
