# PDP10 TOOLS CURRENT STATUS

THIS FILE IS THE SOLE CURRENT STATE DOCUMENT FOR PDP10 TOOLS.

## BUILD STATE

THE HOST TOOLS BUILD SUCCESSFULLY WITH THE CURRENT MAKEFILE AND C HOST COMPILER SETTINGS.

THE DEFAULT MAKE TEST REGRESSION SUITE PASSES ON THE AUDITED SOURCE TREE.

THE MAKEFILE CURRENTLY USES MAKE IMPLEMENTATION EXTENSIONS INCLUDING ?= AND .PHONY.  PORTABLE MAKEFILE CLEANUP IS STILL OPEN.

## LINKER AND OBJECT TOOLS

DLINK CONSUMES DOBJ1 OBJECTS AND DARC1 ARCHIVES AND EMITS DXR V1 EXECUTABLES.

DOBJ1 CARRIES TEXT, DATA, BSS, GLOBAL DEFINITIONS AND IMPORTS, OPTIONAL ENTRY SELECTION, AND LH18/RH18 RELOCATIONS.  LOCAL ASSEMBLER LABELS ARE RESOLVED BEFORE SERIALIZATION.

DARC1 ARCHIVES INDEX EXPORTED SYMBOLS TO MEMBER OFFSETS SO DLINK CAN EXTRACT ONLY MEMBERS REQUIRED BY UNRESOLVED GLOBALS.

DLINK SUPPORTS RELOCATABLE RESIDENT IMAGE PACKAGES WITH -R, -N, AND -X.  PACKAGE OUTPUT CARRIES INITIALIZED WORDS, BSS SIZE, AND LH18/RH18 RELOCATION INFORMATION.

DLINK RECORDS DXR TEXT PURITY.  --PURE IS AN EXPLICIT NO TEXT WRITES CONTRACT.  --IMPURE FORCES THE CONSERVATIVE STATE.  WITHOUT EITHER OPTION, THE STATE IS UNKNOWN UNLESS DLINK PROVES A DIRECT STORE INTO FINAL TEXT, IN WHICH CASE IT RECORDS IMPURE.

DLINK --DAIMOS-UUO-RELAX CAN REPLACE ELIGIBLE DIRECT PUSHJ CALLS TO SIMPLE DAIMOS LIBC VENEERS WITH THE CORRESPONDING MONITOR UUO.  NONDIRECT, INDEXED, INDIRECT, ADDENDED, OR ADDRESS REFERENCES REQUIRE NORMAL SYMBOL RESOLUTION.

PDP10-OBJDUMP INSPECTS DOBJ1 OBJECT CONTENTS AND RELOCATIONS.

## FILESYSTEM AND STORAGE TOOLS

MKDSK BUILDS PDP-6 DSK270 DBOOT DISKSETS.

MKD6FS BUILDS D6FS FILESYSTEMS IN A DBOOT DISKSET.

D6FSCK CHECKS AND CAN REPAIR D6FS FILESYSTEMS.

PACKFS PACKS D6FS ALLOCATED EXTENTS.

D6BAD MANAGES D6FS BAD BLOCK INFORMATION.

LOGSTORE MANAGES THE D6FS LOGSTORE AREA.

D6SWAP INSPECTS AND MAINTAINS THE D6FS SWAP AREA.

## MEDIA AND BOOT TOOLS

MKDT WRITES PDP-6 18 BIT SIMH DECTAPE IMAGES.

MKTAP WRITES PDP-6 36 BIT WORDS AS ODD PARITY 7 TRACK SIMH MAGNETIC TAPE RECORDS.

WORDS2PT ENCODES OCTAL 36 BIT WORDS AS PDP-6 PAPER TAPE BYTES.

MKSTREAM WRAPS ASSEMBLED STANDALONE WORDS AS A STAGE1 STREAM.

MKINITFS0 BUILDS HIERARCHICAL DAIMOS INITFS0 IMAGES AS PDP-10 ASSEMBLY OR OCTAL WORDS.  MKINITFS IS ITS COMPATIBILITY NAME.

MKBOOTBANNER GENERATES THE DAIMOS BOOT BANNER INPUT.

## SIMULATOR SUPPORT

P10RUN DRIVES THE PDP-6, KA10, KI10, KL10, AND KS10 SIMH CONFIGURATIONS STORED UNDER SIMH.

THE DEFAULT FUNCTIONAL TEST CURRENTLY PROVES THE HOST PIPELINE ON KA10 AND ALSO CHECKS THE P10RUN C89 BUILD CONTRACT.
