# PDP10 TOOLS

PDP10 TOOLS IS THE HOST SIDE SUPPORT TOOL COLLECTION FOR THE DAIMOS AND PDP-6/PDP-10 TOOLCHAIN.

THE REPOSITORY CONTAINS LINKING, OBJECT AND ARCHIVE, FILESYSTEM IMAGE, BOOT MEDIA, SIMULATOR, AND CONVERSION UTILITIES.  THE DAS ASSEMBLER IS MAINTAINED IN THE SEPARATE DAS PROJECT.

## BUILD

BUILD ALL HOST TOOLS WITH:

    MAKE

INSTALL THEM UNDER THE PDP-10 TOOLCHAIN PREFIX WITH:

    MAKE INSTALL PDP10_PREFIX=/PATH/TO/PREFIX

REMOVE INSTALLED FILES WITH:

    MAKE UNINSTALL PDP10_PREFIX=/PATH/TO/PREFIX

HOST UNIX COMMANDS AND FILE NAMES ARE PRINTED IN UPPER CASE IN THIS DOCUMENT BECAUSE THE DOCUMENTATION IS SIXBIT CLEAN.  ENTER THEIR NORMAL HOST SPELLING WHEN REQUIRED.

## MAIN TOOLS

- P10RUN - SIMH BARE METAL TEST RUNNER FOR PDP-6 AND PDP-10 SYSTEMS.
- DLINK - STATIC LINKER FOR DOBJ1 OBJECTS AND DARC1 ARCHIVES, PRODUCING DXR V1.
- DARC - DARC1 STATIC ARCHIVE BUILDER.
- PDP10-OBJDUMP - DOBJ1 OBJECT INSPECTION TOOL.
- MKDSK - DSK270 DBOOT DISKSET BUILDER.
- MKD6FS - D6FS FILESYSTEM BUILDER.
- D6FSCK - D6FS CHECK AND REPAIR TOOL.
- PACKFS - D6FS PACKING AND COMPACTION TOOL.
- D6BAD - D6FS BAD BLOCK MAP TOOL.
- LOGSTORE - D6FS LOGSTORE MAINTENANCE TOOL.
- D6SWAP - D6FS SWAP AREA INSPECTION AND MAINTENANCE TOOL.
- MKDT - SIMH DECTAPE IMAGE BUILDER.
- MKTAP - SIMH 7 TRACK MAGNETIC TAPE RECORD BUILDER.
- WORDS2PT - PDP-6 PAPER TAPE ENCODER.
- MKSTREAM - STAGE1 STREAM BUILDER.
- MKINITFS0 - DAIMOS INITFS0 IMAGE BUILDER.
- MKBOOTBANNER - DAIMOS BOOT BANNER GENERATOR.

THE INSTALLED COMPATIBILITY NAMES INCLUDE PDP10-DEC-NONE-DARC, PDP10-DEC-NONE-OBJDUMP, AND MKINITFS.

## TOOLCHAIN FORMATS

DOBJ1 IS THE RELOCATABLE OBJECT FORMAT USED BY DAS AND DLINK.  IT CARRIES TEXT, DATA, BSS, GLOBAL DEFINITIONS AND IMPORTS, ENTRY SELECTION, AND LH18/RH18 RELOCATIONS.

DARC1 IS THE STATIC ARCHIVE FORMAT.  ITS SYMBOL INDEX MAPS EXPORTED SYMBOLS TO ARCHIVE MEMBERS SO DLINK CAN EXTRACT ONLY REQUIRED MEMBERS.

DXR V1 IS THE EXECUTABLE OUTPUT FORMAT USED BY THE CURRENT TOOLCHAIN.  FINAL RIM AND PAPER TAPE CONVERSION IS OWNED BY DAS DXRCONVERT.
